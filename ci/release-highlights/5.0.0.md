### Highlights

* B2B image and video generation, with reference-image and global-context conditioning, mask prediction, LoRA fine-tuning, and configurable temporal conditioning.
* B2B export and inference workflows for ONNX and TensorRT, including class and mask conditioning and optional fixed temporal noise.
* Shortcut-model training and image inference.
* MAT inpainting integration, inference scripts, and motion support.
* Expanded data controls: multiple datasets, bounding-box context crops, fixed masks, temporal sampling, and camera-color and detail augmentations.
* Improved video evaluation, masked B2B metrics, and training continuation support.
* A staged release workflow that validates the GPU server image before publication.

The server image includes the training and HTTP inference interfaces. Optional
deployment backends such as TensorRT require their own runtime dependencies;
the server image is not a TensorRT distribution.
